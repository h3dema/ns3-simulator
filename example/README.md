# Python Scripts for Visualizing State Changes and Energy Consumption:

This example folder contains three Python scripts that help visualize state changes and energy consumption over time. Each script serves a specific purpose and can be used independently.

1. `plot_state_changes.py`: This script plots the state changes over time for a given file. It takes a filename as input and generates a plot showing the transitions between different states. The plot can be displayed or saved as an image.

2. `plot_cap_energy.py`: This script plots the energy consumption over time for a given file. It reads a CSV-like text file and creates a DataFrame using pandas. It then plots one curve per node, showing the energy consumption over time.

3. `check_scenario3.py`: This script processes the log file generated by running `nb-scenario3.cc` and visualizes the transitions of states and energy consumption. It takes the log file as input and generates a plot showing the state transitions and energy consumption over time.

## Scripts

### plot_state_changes.py

This script plots the state changes over time for a given file. It takes a filename as input and generates a plot showing the transitions between different states.

Usage:
```bash
python plot_state_changes.py --fname <filename> [--show]
```

### plot_cap_energy.py

This script plots the energy consumption over time for a given file. It reads a CSV-like text file and creates a DataFrame using pandas. It then plots one curve per node, showing the energy consumption over time.

Usage:
```bash
python plot_cap_energy.py --fname <filename>
```


### check_scenario3.py

This script processes the log file generated by running `nb-scenario3.cc` and visualizes the transitions of states and energy consumption. It takes the log file as input and generates a plot showing the state transitions and energy consumption over time.

Usage:
```bash
python check_scenario3.py --log-fname <log_file>
```


### Requirements

Use pip to install the required dependencies listed in `requirements.txt`:

```bash
pip install -r requirements.txt
```


## Troubleshooting

If you encounter any issues while running the scripts, please check the following:

- Make sure you have the required dependencies installed.
- Verify that the input file exists and is in the correct format.
- Check the command-line arguments and ensure they are provided correctly.
